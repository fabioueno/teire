<div align="center">
  <h1>teire (手入れ)</h1>

  <p>Keeps a machine's dotfiles in the shape that a repository declares.</p>
</div>

---

Teire links files, merges owned keys into JSON files that other programs also
write, and records each apply so that it can tell your changes from a program's
changes.

## Status

Early development. Only `teire version` works today.
